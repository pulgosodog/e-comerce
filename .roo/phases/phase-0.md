# Phase 0 & 1 — Analysis & Mapped Areas

## Summary
This phase involved analyzing the project and mapping out key areas.

## Actions Taken
- Confirmed tech stack (Node.js with Express.js, SQLite via Sequelize ORM, EJS templating engine, HTML/CSS/JavaScript)
- Identified entry points (`server.js`, `models/index.js`, `views/` directory, `public/` directory)
- Documented weaknesses (monolithic server.js, inline JS, duplicated Cart/Search/Sorting logic)
